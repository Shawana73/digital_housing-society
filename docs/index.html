Digital Housing Society

A Flutter-Based Housing Society Management System

Final Year Project | BS Information Technology

About the Project

Digital Housing Society is a mobile application developed to digitize housing society operations and reduce reliance on manual processes.

The system includes applicant management, document verification, plot management and a digital balloting workflow.

Key Features

  • Secure user authentication
  • Applicant and document verification
  • Plot management and visualization
  • Digital balloting system
  • Admin dashboard
  • Reports and analytics

Technology Stack

Flutter · Dart · Firebase Authentication · Cloud Firestore

Provider · MVVM · Git · GitHub · Android Studio
